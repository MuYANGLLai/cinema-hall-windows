cinema-hall（Windows 分发包）源码获取说明
================================================

本程序整体按 GNU General Public License v3.0 分发，许可证全文见同目录 LICENSE。
本包内由本项目编写的全部代码，其对应源码按下述方式获取。

一、本包对应的源码
------------------------------------------------
  仓库地址：https://github.com/MuYANGLLai/cinema-hall-windows
  发布 tag：windows-0.1.4
  （tag 指向的那个提交，就是本包对应的源码。这里刻意不写提交号：
   本文件本身也在源码树里，写死提交号会造成「改了本文件，提交号就失效」的自引用。）

  取得方式（任选其一）：

    git clone https://github.com/MuYANGLLai/cinema-hall-windows.git
    cd cinema-hall-windows
    git checkout windows-0.1.4

    # 或者直接下载该 tag 的归档
    https://github.com/MuYANGLLai/cinema-hall-windows/archive/refs/tags/windows-0.1.4.zip

  这个仓库里有什么：
    desktopApp/、desktop/{rtc,media,library}、
    core/{session,network,protocol,model,rtc,media,library}，
    以及 README（构建方法）、LICENSE、第三方组件清单、开源前许可核对与证据表。
  没有什么：
    Android 客户端（app/、feature/、core/*-android）与 Node.js 信令服务（server/）。
    它们是另外两个可独立分发的作品，与本包的对应源码无关；构建本包不需要它们。

  构建前提：JDK 17 或更高，**不需要 Android SDK**。
  构建（产物在 desktopApp/build/compose/binaries/main/app/cinema-hall/）：
    ./gradlew :desktopApp:createDistributable
  要打成 zip（发布分发包就是它的产物）：
    ./gradlew :desktopApp:releaseZip

  运行时前提：需要 VLC 3.0.21。本源码仓库不含其二进制（体积与源码义务都不适合放
  源码仓库）；官方分发包是把它放在程序目录的 vlc/ 下随包分发的。

二、第三方组件各自的源码
------------------------------------------------
  VLC 3.0.21（含 libVLC）   https://code.videolan.org/videolan/vlc/-/tree/3.0.21
  vlcj 4.12.1 / natives      https://github.com/caprica/vlcj
  webrtc-java 0.14.0         https://github.com/devopvoid/webrtc-java
  FFmpeg（webrtc-java 内置）  https://ffmpeg.org/releases/
  JNA 5.16.0                 https://github.com/java-native-access/jna
  SLF4J 2.0.16               https://github.com/qos-ch/slf4j
  Kotlin / Compose / skiko / androidx
                             见源码仓库的 gradle/libs.versions.toml 与 第三方组件清单.md

三、我们的改动
------------------------------------------------
  未对上述任何第三方组件做修改。
  vlc/ 目录为 VLC 3.0.21 官方 Windows 构建产物原样拷贝，仅剔除了
  axvlc.dll 与 npvlc.dll 两个浏览器嵌入插件（它们不参与播放，
  且其对应源码不在 VLC 源码包内，见 第三方组件清单.md §6）。

四、jwebrtc.dll 内静态链接的 FFmpeg（LGPL-2.1 §6）
------------------------------------------------
  我们不修改 FFmpeg，也不修改 webrtc-java，仅原样分发其构建产物。
  该 DLL 的构建发生在上游 webrtc-java 项目，我们不具备其构建环境，
  因此无法直接提供该 DLL 的目标文件。
  若你需要 LGPL-2.1 §6 意义上的可重链接材料，请通过仓库 issue 联系我们，
  由我们向上游索取后转交；也可按上游脚本自行重建该 DLL。
